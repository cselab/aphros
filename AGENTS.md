# AGENTS.md

Guidance for coding agents working in this repository.

Aphros: finite volume solver (C++14, CMake, MPI) for incompressible multiphase
flows with surface tension (PLIC VOF, Multi-VOF, particle-based curvature).

## Environment and build

Everything assumes the environment from `deploy/`:

```
cd deploy && ./install_setenv PREFIX   # installs ap.setenv
. ap.setenv                            # sets APHROS_PREFIX, PATH (ap.* scripts)
cd deploy && mkdir build && cd build && cmake .. && make -j4 && make install  # hypre, overlap, fpzip, scripts
```

CMake fails without `APHROS_PREFIX` (`src/client.cmake`). Build the code
(out-of-source only):

```
cd src && make            # = mkdir build; cmake ..; make; make install
cd src && make js         # emscripten build into src/buildjs
```

Options are in `src/CMakeLists.txt` (`USE_MPI`, `USE_HDF`, `USE_HYPRE`,
`USE_AVX`, `USE_OPENMP`, `USE_DIM1..4`, `USE_BACKEND_*`, `USE_TESTS`, ...),
e.g. `cmake .. -DUSE_MPI=0 -DUSE_HDF=0`. `USE_HDF` requires `USE_MPI`.
Build without CMake: `src/Makefile_legacy` after `../make/bootstrap` (see README).

`make install` is required before running tests or examples: tests call
installed `ap.*` scripts and the Python module `aphros` (`deploy/scripts/aphros`).

## Tests

```
cd src && make test                          # ctest -j in src/build
cd src/build && ctest -R advection           # tests matching regex
cd src/build && ctest -N                     # list tests
cd src/build/test/advection && ./test 2d -c native -b 16   # run one case directly
```

Each test is a directory `src/test/NAME/` with `main.cpp` (binary `t.NAME`),
`CMakeLists.txt` (uses `add_test_current(NAME ... COMMAND ...)`), and
usually a Python driver `test` derived from `aphros.TestBase`, which runs the
case and compares output against `ref/` with a tolerance. Tests are discovered
by globbing directories; no central list. Each test should have a `Simple()`
in namespace `simple` as a minimal example of the feature.

Examples: `examples/NNN_name/`, built in CI with `cd examples && make build`.
Simulations run via `make run` with `include $(shell ap.makesim)`
(`deploy/scripts/sim_base.makefile`), which assembles `a.conf`, `base.conf`,
`std.conf`, `mesh.conf` and runs `ap.mfer`.

## Formatting

- C++: `tools/format` (clang-format 23.1.3 via `uvx`, `.clang-format`);
  `tools/format --check` runs in CI. Excludes `doc/`, `src/CubismNoCopy/`,
  `src/overlap/`.
- Python: `yapf -ir .` (`.style.yapf`).
- `README.md` is generated by `README.py`; edit `README.py`.

## Architecture

- **Configuration**: text files with `set TYPE NAME VALUE` / `include` parsed
  into `Vars` (`src/parse/vars.h`, `parser.h`). Defaults and documentation of
  parameters: `deploy/scripts/sim_base.conf`.
- **Mesh and fields** (`src/geom/`): `MeshCartesian<Scal, dim>` is one block
  with halo cells; `FieldCell`, `FieldFace`, `FieldNode`; index types
  `IdxCell`, `IdxFace`; loops `for (auto c : m.Cells())`. Embedded boundaries
  wrap the mesh: `Embed<M>` (`solver/embed.h`).
- **Suspender / stages** (`src/util/suspender.h`): solver methods are split
  into stages:
  ```
  auto sem = m.GetSem("name");
  if (sem("stage1")) { ...; m.Comm(&fc); m.Reduce(...); }
  if (sem.Nested("stage2")) { solver->Step(); }
  ```
  Each call runs one stage on every block; communication and reductions
  requested in a stage complete before the next stage. Code between stages
  cannot keep local variables; persistent state goes in members or
  `sem.GetContext<T>()`.
- **Distr backends** (`src/distr/`): `DistrMesh<M>` owns blocks and drives
  the kernel stage by stage, doing halo exchange and reductions. Backends
  (`local` shared memory, `native` MPI 2D/3D, `cubismnc` MPI 3D) register
  through `ModuleDistr<M>` (`util/module.h`) and are selected by
  `set string backend`. `DistrSolver<M, Kernel>` wires a kernel to a backend.
- **Kernel** (`src/kernel/hydro.*`): `Hydro<M>` is the main multiphase
  simulation (`ap.mfer` → `aphros_c` → `RunMpi` → `DistrSolver<M, Hydro<M>>`).
  It composes solvers from `src/solver/`: fluid (`proj` = Bell-Colella-Glaz
  projection, `simple` = SIMPLE), interface advection (`vof`, `vofm` =
  Multi-VOF), curvature (`curv`, `partstr`), `tracer`, `particles`,
  `electro`, `convdiff*`. Linear solvers (`src/linear/`: hypre, conjugate
  gradient, AMGX, OpenCL) are also modules chosen by config.
- **Templates and instantiation**: implementation lives in `.ipp`; the `.cpp`
  includes it and explicitly instantiates for each enabled dimension with the
  `MULTIDIMX` macro (`#define X(dim) template class Foo<MeshCartesian<double, dim>>;`).
  New templated classes need the same.
- **Libraries**: each component is an object library declared with
  `add_object()` / `object_link_libraries()` in its `CMakeLists.txt` and must
  be listed in `ObjLibs` in `src/CMakeLists.txt` to end up in `libaphros.so`.
  External projects link against the installed package (`aphrosConfig.cmake`,
  see `examples/006_cmake`).
- `src/aphros_c/` is the C API used by `ap.mfer` (`src/main.c`) and the
  WebAssembly demos.
